## 01 · About

I am Daniel, a developer focused on building practical and maintainable software.

My main direction is **desktop development with C++ and Qt**, supported by backend logic, database work and constant algorithm practice. I like projects where the interface is not just visual decoration, but a clear layer over a solid internal system.

I care about code that can be opened later and still make sense.

<br/>

> **Developer manifesto**
>
> Build small.
> Think clearly.
> Name things honestly.
> Remove what does not help.
> Leave the codebase better than it was.
